# TravelBliss-API

GraphQL API (Apollo Server, type-graphql, TypeORM/Postgres, Redis) for TravelBliss.

- Package manager: pnpm.
- `pnpm test` is the full gate (typecheck, prettier, lint, vitest, build). `pnpm typecheck` for a quick check.
