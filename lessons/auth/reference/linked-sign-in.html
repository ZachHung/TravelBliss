Reference

Linked sign-in

Google or Facebook instead of a password. Module apps/api/src/modules/linked-sign-in/; decisions in docs/adr/0005-linked-sign-in.md.

The round trip

Step Where What
1 Start startLinkedSignIn mutation → LinkedSignInService.start Redis linkedSignInFlow:<state> = { provider, codeVerifier, userId? }, 10 min · cookie travelBliss_ls = sign-in|connect:<state>, path /auth · returns the consent URL
2 Consent Google / Facebook redirects to /auth/<provider>/callback?code&state
3 Callback linked-sign-in.routes.ts → finish three checks → code + verifier → profile → userFor
4 Session SessionService.start(userId, { remember: true }) sets rf (sign-in only; connect starts no session)
5 Land 302 to the web app / · /account when connecting · ?error=<ErrorCode> on failure; reload refresh gives the access token

Checks on the callback

  1. URL state = cookie state (binds the trip to this browser; RFC 6749 §10.12)
  2. GETDEL finds the flow, for this provider (once, within 10 min)
  3. code is present (missing = cancelled) and trades with the PKCE verifier

Which user (userFor)

Situation Signing in Connecting (as Ann)
sub linked to X sign in as X X = Ann: nothing changes · else LINKED_SIGN_IN_TAKEN
sub not linked, email belongs to a user EMAIL_TAKEN_SIGN_IN_TO_LINK link to Ann
sub not linked, email new or absent new passwordless user + link (one transaction) link to Ann

Match on (provider, providerUserId), unique. Never on email (OIDC Core §5.7; registration does not verify emails).

Error codes

Code Means
LINKED_SIGN_IN_FAILED cancelled, expired, replayed, forged state, or the provider refused
EMAIL_TAKEN_SIGN_IN_TO_LINK sign in with your password, then connect from the account page
LINKED_SIGN_IN_TAKEN this provider account belongs to another user
LAST_SIGN_IN_METHOD disconnect would leave no password and no linked sign-in

Adding a provider

One file implementing SignInProvider (authorizationUrl, fetchProfile), one entry in providers/index.ts, one SignInProviderName, one providerDetails entry on the web. Offered only when its credentials are set; DEV only under NODE_ENV=local|e2e.
