Reference

The access token

header.payload.signature   (each part base64url)
Part TravelBliss contents Readable by
Header { "alg": "HS256", "typ": "JWT" } anyone
Payload { userId, iat, exp }: seconds since 1970; exp − iat = API_JWT_EXPIRED anyone
Signature HMAC-SHA256 of header + payload with API_SECRET_JWT (32 bytes) meaningful only to the API

Issue and check

// createTokens, at sign-in
sign({ userId }, API_SECRET_JWT, { expiresIn: API_JWT_EXPIRED })

// verifyToken, on every request
verify(token, API_SECRET_JWT)   // throws on any problem → caller is a guest
Token verify Caller
as issued, before exp returns the payload signed-in user
any byte of header or payload edited invalid signature guest
signed with another secret invalid signature guest
past exp jwt expired guest

Rules

  • Reading a token needs nothing; minting one the API accepts needs the secret.
  • The payload is public: an id, never a password or anything private.
  • decode reads without checking; only verify decides trust (jsonwebtoken).
