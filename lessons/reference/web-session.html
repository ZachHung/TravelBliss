createSessionLink

Step Rule
Attach Authorization: Bearer <in-memory token> when there is one
Retry on UNAUTHENTICATED only → refresh → resend once (retried)
Never retry RefreshToken itself; retry an operation twice
Dedupe one pending refresh per page (tab); others await it

Reload

token null → GetMe → UNAUTHENTICATED → refresh with cookie → retry → user. SessionProvider shows the loader until this settles; then the guards run.

Guard No user User
ProtectedRoute → /sign-in, state.from = here render
PublicRoute render → state.from or /

Sign-out

Client: logout mutation, setAccessToken(null), isSignedOut. Server (end): blacklist this access token until exp, delete this device's refresh key, clear cookie.
