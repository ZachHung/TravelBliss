Glossary

Every lesson uses these words exactly. Repo-wide terms also live in the root GLOSSARY.md.

Term Meaning in TravelBliss
Authentication Answering who are you? Done once per request by SessionService.authenticate. [OWASP]
Authorization Answering what may you do? Done per field by @Authorized and the authChecker. Always after authentication.
Access token The short-lived string the API issues at sign-in. The web app sends it on every request as Authorization: Bearer <token>.
Bearer token A token anyone holding it can use, with no further proof. [RFC 6750 §1.2] The access token is one.
JWT (JSON Web Token) The access token's format: header.payload.signature, each part base64url. [RFC 7519 §3]
Claim One fact in the payload: userId, iat (issued at), exp (expires). Readable by anyone.
Signature HMAC of header + payload with the secret. Any edit, or another secret, makes it fail to verify.
Secret (API_SECRET_JWT) Key only the API holds. Needed to mint a valid token, not to read one.
Signed-in user The User a request acts as: ctx.auth.user on the API, useSession().user on the web.
Guest A caller with no valid session: ctx.auth is undefined.
Role USER or ADMIN, stored on the user. Only checked when a decorator lists roles.
Context (ctx) Per-request object every resolver receives: { req, res, auth }. Built before any field runs.
@Authorized type-graphql decorator that guards a field. Empty means any signed-in user; with roles, one of those roles.
authChecker Our function type-graphql calls for each guarded field. Returns true or false; never touches the database.
UNAUTHENTICATED Error code when a field with @Authorized() (no roles) is denied.
UNAUTHORIZED Error code when a field with @Authorized(roles…) is denied, even for a guest.
